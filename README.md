# Landing Page Institucional - PAC 3C Services

Proposta de landing page institucional desenvolvida para apresentar os servicos da PAC 3C Services, com foco em comunicacao digital, organizacao de informacoes e experiencia do usuario.

## Demonstracao

Acesse a pagina publicada:

https://pac-3c-services.vercel.app/

## Objetivo

O projeto foi criado para estruturar uma presenca digital voltada a apresentacao de servicos, organizando as informacoes de forma clara, visual e orientada a navegacao do usuario.

## Funcionalidades

- Apresentacao institucional de servicos
- Organizacao de conteudo em secoes
- Estrutura de navegacao
- Layout voltado para comunicacao digital
- Chamadas para acao (CTAs), quando aplicavel

## Como executar localmente

1. Clone este repositorio:

```bash
git clone https://github.com/Rhenan-amorim/pac3c.git
```

2. Acesse a pasta do projeto:

```bash
cd pac3c
```

3. Instale as dependencias:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

5. Abra o endereco exibido no terminal no navegador.
